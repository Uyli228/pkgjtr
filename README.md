# pkgjtr

## Чотири Кути — ігри на 1–4 гравців для телефона

Гра лежить у теці [`game/`](game/README.md): 32 міні-гри, турніри як в оригіналі (рулетка, зірки, фінальна дуель, п’єдестал), боти.
Android: встановіть [`dist/chotyry-kuty.apk`](dist/chotyry-kuty.apk) — грає без інтернету.
Будь-який телефон: відкрийте в браузері [`dist/chotyry-kuty.html`](dist/chotyry-kuty.html).
