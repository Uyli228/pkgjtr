# Аудит міні-ігор

## Прохід «простоти» (версія 1.4)

Відгук: ігри перевантажені. У скіл party-minigame-design додано жорсткі межі простоти (§0): одна механіка, максимум 3 види об'єктів, жодного тексту під час гри, правило ≤ 60 символів, 1–3 однакові раунди. В аудит додано блокувальну колонку «Простота».

| Гра | Що було зайве | Рішення |
|---|---|---|
| Аукціон наосліп | цінність, шанс, ціна, 5 лотів | прибрано |
| Хто з них ти? | дві дії (крок / постріл), пошук себе в натовпі | прибрано |
| Пастка для друга | дві фази (розставити / бігти) | прибрано |
| Лазерна стеля | неочевидне правило «очки лише лідеру» | прибрано |
| Джекпот привидів | фальшиві вибухи привидів | лише «тримай — відпусти вчасно», 2 раунди, назва «Джекпот» |
| Спільна вежа | вітер від суперників, лічильник поверхів | лише ходи по черзі |
| Чий торт? | +2 лідеру, 0 останньому | влучив +1, у себе −1; 3 раунди |
| П’ять фруктів | помилка дає очки всім, до 5 | помилка −1 собі, до 3 |
| Жаб'ячий язик | золоті мухи, оси, до 10 | лише мухи, до 5 |
| НЛО-збирачі | великі зірки, діри крадуть зірки | діра просто відкидає на старт |
| Остання секунда, Дракон, Керлінг | 3–4 раунди + написи «РАУНД x/y» | 2 раунди, без написів |
| Усі ігри | правила до 110 символів | правила до 60 символів |

Нові прості ігри: **Спільна кулька** (дмухай раз на 3 с, хто лусне — вибув), **Скакалка** (тап — стрибок), **Стільці** (музика стихла — сідай).

## Що змінено за результатами

**Для всіх ігор (рушій, скіл game-feel-juice)**
- Кожен гравець тепер — колобок-персонаж свого кольору з емоціями (`E.avatar`): спокійний, хитрий, наляканий, побитий, вибулий, щасливий.
- Стоп-кадр на головних подіях (`E.hitstop`), червоний спалах і тремтіння при вибуванні, «підстрибування» очок.
- Фінал раунду: переможець стрибає в короні, решта засмучені.
- Інтро в стилі WarioWare: велике дієслово («НЕ БУДИ!», «БЛЕФУЙ!») і правило ≤ 110 символів замість абзацу.
- Повага до «зменшеного руху» в налаштуваннях телефона (менше тремтіння й частинок).

**Окремі ігри**
- **Вежа → Спільна вежа**: одна вежа на всіх, ходи по черзі; хто чекає — тапами дме вітер і заважає. Була кліше-«стекером» без взаємодії.
- **Пастка для друга** (нова): правило Ultimate Chicken Horse — очко тільки якщо хтось інший упав.
- **Остання секунда**: дробові очки (менше нічиїх — було 33 %), 3 раунди замість 4.
- **Орбіта**: швидше наростання складності (було 38 с).
- **НЛО-збирачі**: 30 с замість 35.
- **Прибрано** (≤ 4 балів, кліше або без драми між людьми): Порахуй котиків, Стрибунці, Ритм-барабан, Кошик, Каньйон.

## Що лишається слабким
- **Лазерна стеля, Секундомір, Паркування** — гравці мало впливають один на одного (бал 5–6). Кандидати на переробку наступними.
- **Паркування, Курча на рейках** — з ботами тривають 3–4 с; з людьми довше, але варто додати другу спробу або раунди.
