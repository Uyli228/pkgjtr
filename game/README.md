# Чотири Кути

Вечірка на одному телефоні: 1–4 гравці, 20 міні-ігор, турніри, боти, статистика.
Кожен гравець тисне лише свою кольорову кнопку: у грі на двох — верх і низ екрана, на трьох-чотирьох — кути.
Текст для гравців зверху дублюється догори дриґом, щоб усі могли читати.

## Як запустити на телефоні

- **APK для Android (без інтернету).** Скачайте `dist/chotyry-kuty.apk` на телефон і відкрийте його.
  Android попросить дозволити встановлення з цього джерела (браузера чи файлового менеджера) — дозвольте.
  Потрібен Android 7.0 або новіший. Гра повністю всередині APK, інтернет не потрібен.
- **Один файл.** Скиньте `dist/chotyry-kuty.html` на телефон і відкрийте в браузері (Chrome / Safari).
- **Як застосунок.** Викладіть теку `game/` на будь-який хостинг з HTTPS (наприклад, GitHub Pages:
  Settings → Pages → Deploy from branch → `main` / root, тоді гра буде за адресою `…/pkgjtr/game/`).
  Відкрийте адресу на телефоні → «Встановити» (Android) або «Поділитися → На початковий екран» (iPhone).
  Після першого відкриття гра працює без інтернету.
- **На комп'ютері:** `npx http-server game` і відкрийте `http://localhost:8080`.
  Клавіші: 1-й гравець — `A`, 2-й — `L`, 3-й — `Q`, 4-й — `P` (або цифри `1–4`).

## Що є

- Вибір кількості гравців 1–4; кожне місце можна зробити гравцем, ботом або вимкнути (1 гравець = гра проти бота).
- **Міні-ігри** — будь-яка з 20 на вибір, «Ще раз» / «Інша гра».
- **Випадкова гра** — одразу в бій.
- **Турнір** — до 3 / 5 / 7 / 10 перемог, свій набір ігор, табло з коронами, тай-брейк, екран чемпіона з історією.
- Боти трьох рівнів складності, звук (синтезований, без файлів), вібрація, повноекранний режим, пауза, статистика перемог.

## 20 міні-ігор

Кожна гра — одна проста ідея: одне дієслово, правило до 60 символів, без тексту під час гри.
Перші дев'ять придумані за дослідженням ([`reports/`](../reports/)), перевірка — [`docs/minigame-audit.md`](../docs/minigame-audit.md).

## Структура

```
game/
  index.html          меню та розмітка
  css/style.css       оформлення
  js/engine.js        рушій: розкладка кнопок, мультитач, боти, звук, фази гри
  js/games/*.js       20 міні-ігор (кожна — окремий файл)
  js/app.js           меню, турнір, налаштування, статистика
  sw.js, manifest.webmanifest, icons/   встановлення й офлайн
android/              обгортка для Android: маніфест, MainActivity (smali), іконки, підпис
tools/build.mjs       збирає все в dist/chotyry-kuty.html
tools/build-apk.sh    збирає dist/chotyry-kuty.apk (потрібні Java, Maven, Python;
                      aapt2, smali й apksig скачуються з Maven Central)
```

Ключ підпису `android/chotyry-kuty.p12` (пароль `chotyrykuty`) лежить у репозиторії навмисно:
так нові версії APK встановлюються поверх старих без видалення. Для публікації в Google Play
створіть власний ключ і тримайте його в секреті.

Нова гра — це файл у `js/games/`, що викликає `G.game({ id, name, icon, tag, desc, btn, create(E) { … } })`,
і рядок `<script>` в `index.html` (та назва файлу в `sw.js`). Після змін: `node tools/build.mjs` і `./tools/build-apk.sh`.

## Скіли для розробки ігор

У `.claude/skills/` лежать три скіли для Claude Code, які підхоплюються в цьому репозиторії:

- **party-minigame-design** — як придумати міні-гру: формула веселої party-гри, дієслова однієї кнопки, заборонені кліше, як підключити гру до рушія.
- **game-feel-juice** — як зробити гру «соковитою»: персонажі з емоціями, стоп-кадр, спалахи, смішна поразка.
- **minigame-audit** — як перевірити всі ігри: `node tools/audit.mjs` (боти грають кожну гру), оцінка за 10 критеріями, звіт у `docs/minigame-audit.md`.
