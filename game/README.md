# Чотири Кути

Вечірка на одному телефоні: 1–4 гравці, 20 власних міні-ігор, турніри, боти, статистика.
Кожен гравець тисне лише свою кольорову кнопку: у грі на двох — верх і низ екрана, на трьох-чотирьох — кути.
Текст для гравців зверху дублюється догори дриґом, щоб усі могли читати.

## Як запустити на телефоні

- **Один файл.** Скиньте `dist/chotyry-kuty.html` на телефон і відкрийте в браузері (Chrome / Safari).
- **Як застосунок.** Викладіть теку `game/` на будь-який хостинг з HTTPS (наприклад, GitHub Pages:
  Settings → Pages → Deploy from branch → `main` / root, тоді гра буде за адресою `…/pkgjtr/game/`).
  Відкрийте адресу на телефоні → «Встановити» (Android) або «Поділитися → На початковий екран» (iPhone).
  Після першого відкриття гра працює без інтернету.
- **На комп'ютері:** `npx http-server game` і відкрийте `http://localhost:8080`.
  Клавіші: 1-й гравець — `A`, 2-й — `L`, 3-й — `Q`, 4-й — `P` (або цифри `1–4`).

## Що є

- Вибір кількості гравців 1–4; кожне місце можна зробити гравцем, ботом або вимкнути (1 гравець = гра проти бота).
- **Міні-ігри** — будь-яка з 20 на вибір, «Ще раз» / «Інша гра».
- **Випадкова гра** — одразу в бій.
- **Турнір** — до 3 / 5 / 7 / 10 перемог, свій набір ігор, табло з коронами, тай-брейк, екран чемпіона з історією.
- Боти трьох рівнів складності, звук (синтезований, без файлів), вібрація, повноекранний режим, пауза, статистика перемог.

## 20 міні-ігор

| # | Гра | Суть |
|---|-----|------|
| 1 | Дуель | Тисни лише на «ВОГОНЬ!», слова-пастки («ВОДА!», «ВОРОНА!») — фальстарт |
| 2 | Кольоровий хаос | Тисни, коли колір літер збігається зі словом |
| 3 | Вежа | Скидай блок, що їздить, — звисле відрізається; хто перший 10 поверхів |
| 4 | Бомба | Натисни стільки разів, скільки крапок на бомбі, щоб передати її далі |
| 5 | Жаб'ячий язик | Приціл гойдається — стріляй язиком у мух, обминай ос |
| 6 | Повітряна кулька | Накачуй якнайбільше, але не лусни — межа в кожного своя |
| 7 | Секундомір | Утримай кнопку рівно N секунд, таймер ховається |
| 8 | Порахуй котиків | Порахуй котиків серед звірят, відповідь — натисканнями |
| 9 | Мишка і кіт | Крадись до сиру, завмирай, коли кіт прокидається |
| 10 | Ножі в колоду | Кидай ножі в колоду, що крутиться, не влучаючи в інші |
| 11 | Паркування | Газуй і зупинись точно в рамці, не вріжся в стіну |
| 12 | Курча на рейках | Зістрибни з рейок якомога пізніше перед потягом |
| 13 | Канат | Тисни швидше за всіх, щоб затягти вузол у свою зону |
| 14 | НЛО-збирачі | Тарілка летить сама, тримай для повороту, збирай зірки, тікай від чорних дір |
| 15 | Стрибунці | Біжи й перестрибуй перешкоди (коротко/довго), під високими птахами — не стрибай |
| 16 | Орбіта | Перескакуй між двома орбітами, ухиляючись від уламків |
| 17 | Ритм-барабан | Тисни в такт нотам, що падають |
| 18 | Кошик | Розвертай кошик, лови фрукти й зірки, уникай бомб |
| 19 | Керлінг-бум | Шкала сили гойдається — запусти шайбу якнайближче до центру, 3 кидки |
| 20 | Каньйон | Тримай — ракету зносить праворуч, відпусти — ліворуч; не торкайся стін |

## Структура

```
game/
  index.html          меню та розмітка
  css/style.css       оформлення
  js/engine.js        рушій: розкладка кнопок, мультитач, боти, звук, фази гри
  js/games/*.js       20 міні-ігор (кожна — окремий файл)
  js/app.js           меню, турнір, налаштування, статистика
  sw.js, manifest.webmanifest, icons/   встановлення й офлайн
tools/build.mjs       збирає все в dist/chotyry-kuty.html
```

Нова гра — це файл у `js/games/`, що викликає `G.game({ id, name, icon, tag, desc, btn, create(E) { … } })`,
і рядок `<script>` в `index.html` (та назва файлу в `sw.js`). Після змін: `node tools/build.mjs`.
